Four lines to first sound.

The SDK speaks Opus, WebTransport, and plain WebAudio. Install, join, publish. Everything underneath is our problem.

quickstart.js 
import { Oscilla } from "@oscilla/sdk";

const room = await Oscilla.join("room_7f3k", { region: "auto" });
room.publish(micStream);
room.on("peer", (p) => p.stream.play());

Install with npm i @oscilla/sdk. The browser build is 11 kB gzipped and has no native dependency.
