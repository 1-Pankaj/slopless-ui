# Code of conduct

Be straightforward and kind. This repository holds a small tool with a
small rule set, and the same plainness applies to how people treat each
other here.

- Critique work, not people. Design taste is subjective; the test suite
  is not. Disagree with the suite by opening an issue, not by being rude.
- Assume competence. Most contributions come from people shipping real
  work under deadline.
- No spam, no self-promotion in issues, no filler comments. If a comment
  could not pass the skill's own copy rules, rewrite it.
- The maintainer may remove comments or block accounts that make the
  repository unpleasant. Report problems through a private message to the
  maintainer's GitHub profile.

This document is short on purpose. It carries the same expectations as a
longer one.
